**API** (Application Programming Interface) je domluvené rozhraní mezi dvěma programy — jídelní lístek restaurace. Objednáš podle lístku a jídlo dostaneš, aniž vidíš do kuchyně. Stejně si jeden program přes API řekne, co potřebuje, a druhý mu vrátí výsledek; vnitřek toho druhého znát nemusí.

Přesně takhle si appky půjčují schopnosti a data cizích služeb: appka počasí se ptá serveru meteoslužby, mapa v e-shopu je objednaná od mapové služby, „přihlášení přes Google" i „appka umí AI" bývá taky volání API na cizí server. API je domluvený jazyk téhle výměny — přesně říká, jak se zeptat a v jakém tvaru přijde odpověď. Díky tomu nikdo nemusí stavět všechno sám: tvůrce poskládá hotové služby a soustředí se na vlastní nápad. **API je jídelní lístek digitálního světa: objednáš si výsledek a kuchyni řešit nemusíš.**
