**👀 Side trip** · [Internet at the cabin](#expedice-stroje-a-site-en)

The router and the server from the expedition actually run on Linux. Open copy.sh/v86 and start a small Linux right in a browser tab. You can’t break anything at home. Try these commands: ls (what’s in the folder), ps (which processes are running, that is, who the shift manager is serving right now), free (how much working memory is free), cat /proc/cpuinfo (what the system thinks about the processor). Then create a file with the command echo hello > test.txt and reload the page. The file has vanished. Explain why: the whole computer lived only in your browser’s working memory. It’s the same lesson as the unsaved school report in the core “Inside a device”.
