**🔬 Side trip** · [Internet at the cabin](#expedice-stroje-a-site-en)

Filius showed you the principle. Cisco Packet Tracer is a simulator that future network engineers learn on, and you set up its routers with the same commands as in a real company. It’s free, but it needs a Cisco Networking Academy account, so create it with a parent or through a teacher. The interface and the course are in English. Build the cabin network in it again and add a second router with two routes to the server. Switch off one link and watch whether the routers find a detour by themselves. This is exactly what you do by hand in the levels of the game “Network routes”: now an algorithm works it out for you.
