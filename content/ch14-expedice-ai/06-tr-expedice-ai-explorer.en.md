**👀 Side trip** · [The bird feeder model](#expedice-ai-en)

Open [TensorFlow Playground](https://playground.tensorflow.org/) (in English, no account). Pick the data with four squares; that’s the XOR from the game *One neuron, one line*. Remove all hidden layers and start the training. The network gets stuck at a straight line and makes mistakes. Now add **one hidden layer**. What is the smallest number of neurons it needs for the test loss to drop below 0.1? Then switch to the **spiral** and look for the smallest network that can handle it. Write down the number of layers, neurons and epochs. Finally add noise and watch for when the network starts learning the noise instead of the shape. That’s **overfitting**: the model remembers the training data but fails on new data.
