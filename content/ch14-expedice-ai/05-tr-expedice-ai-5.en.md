**🚀 Project** · step 5 of 5 · [The bird feeder model](#expedice-ai-en)

Build a small project in which a model does something:
- a **Scratch game** that reacts to your gestures or words, using [Machine Learning for Kids](https://machinelearningforkids.co.uk/) (interface in Czech);
- or a **micro:bit** that recognises a movement and lights something up, using CreateAI and MakeCode;
- or a **sorter** made with Teachable Machine (for example sorting rubbish: paper, plastic, glass).

Write a **model card** for the project. Real developers write them so that others know what a model is for and when not to trust it:

| field | what you write |
|---|---|
| What it recognises | the classes and what it’s for |
| Data | how many examples in each class, where from, who gave consent |
| Test | accuracy overall **and for each class**, on data the model hasn’t seen |
| Where it fails | at least one situation your tests revealed |
| What not to use it for | when it would be dangerous or unfair to use the model |
| Help from AI | what AI helped you with (for example a chatbot with code) |

**Success criterion:** the project runs, the test is on new data and the card has all six fields. Show the project in the author studio or in the class gallery.
