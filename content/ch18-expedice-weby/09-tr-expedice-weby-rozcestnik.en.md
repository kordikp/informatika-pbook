Real tools, communities, competitions and projects where you can keep going. This selection is from October 2026: rules, prices and dates change, so always check them on the website. Before you sign up anywhere, read the page [Safe in communities](#bezpecne-v-komunitach-en).

### 🛠 Tools

#### [Neocities](https://neocities.org)

Free hosting for static websites, with an editor right in the browser and a community of personal websites.

:::reveal How to start
You upload index.html without installing anything and in a few minutes you have an address. It’s the shortest way from a file to a website anyone can open.

*basic website free, paid membership optional · The terms of service don’t state a minimum age explicitly. Under 13, set up the account with a parent, using their e-mail · interface in English*

1. With a parent, set up an account and choose a nickname, not your name.
2. In the editor on the website, open index.html and write a heading and a paragraph.
3. Save it and open the address prezdivka.neocities.org on your phone over mobile data.
:::

#### [GitHub Pages](https://pages.github.com)

Free website hosting straight from a repository on GitHub, with https.

:::reveal How to start
Professionals use the same tool. Along the way you’ll learn about versions and the history of changes (Git).

*free · GitHub from age 13. Younger kids only through a parent’s account, or wait and use Neocities with a parent · in English*

1. Create a repository prezdivka.github.io.
2. Upload index.html into it with the Add file button.
3. In Settings → Pages, check the address and open it a minute later.
:::

#### [Code.org Web Lab](https://code.org/tools/web-lab)

A browser environment for building simple websites in HTML and CSS. The new version can do JavaScript too.

:::reveal How to start
You see the code and the result side by side, and you don’t have to install or upload anything. Good for experiments before your own hosting.

*free (non-profit Code.org) · from age 13 according to the tool’s page; younger kids at school through a teacher’s class · in English*

1. Open studio.code.org/projects and click the Web Lab tile.
2. Edit the sample page and watch the preview.
3. Try adding a button with a script in the new version with JavaScript.
:::

#### [Flexbox Froggy and Grid Garden (Codepip)](https://flexboxfroggy.com)

Browser games where you lay out a page using CSS flexbox (frogs onto lily pads) and CSS grid (watering carrots).

:::reveal How to start
Layout is what the core of the world leaves out. Here you’ll train it through play, with instructions written in Czech.

*playing in the browser is free · no account, no age limit · Czech, Slovak, Hungarian, English and others*

1. In the language menu, choose Česky.
2. Play Flexbox Froggy right up to the last level.
3. Continue to Grid Garden, the link is on the game’s page.
:::

### 👥 Communities

#### [Hack Club](https://hackclub.com/)

*a community and project programmes for teenagers, clubs all over the world · free · in English*

:::reveal How to join
**Age:** 13–18 years

1. From age 13 with your parents’ knowledge: parents can find information at hackclub.com/parents.
2. Choose a programme that rewards a finished project, such as a website.
3. Younger kids just read the website and get inspired by projects without an account.
:::

> **Stay safe:** A nickname instead of your name, no school or address. Never send anyone passwords or SMS codes, and don’t pay for anything. If someone writes you something weird in private, don’t reply, show it to a parent and block them.

#### [js13kGames](https://js13kgames.com)

*online competition: a web game under 13 kB on a theme announced at the start, every year from August to September · free · in English*

:::reveal How to join
**Age:** for under-18s, fill in the entry with a parent (check the age rules on the competition website)

1. Read the rules and this year’s theme.
2. Build the game in pure HTML, CSS and JavaScript, and keep an eye on the size of the zipped file.
3. Sort out the entry and publishing with a parent.
:::

> **Stay safe:** Put a nickname on the game’s page, not your name and photo. Share code, never passwords. Read the comments on your game, but don’t carry on private conversations with strangers.

#### [Gamedev.js Jam 2026](https://itch.io/jam/gamedevjs-2026)

*a game jam for web games on itch.io (the 2026 jam ran from 13 to 26 April) · free · in English*

:::reveal How to join
**Age:** sort out an itch.io account with a parent according to the terms of service; younger kids through a parent’s account

1. Follow the jam’s page for the next one.
2. First go through the games from last year’s jam and try them in your browser.
3. Upload your game through an account your parent knows about.
:::

> **Stay safe:** No personal details in your profile or in the game. Don’t pay for anything and don’t click links from strangers. Show weird messages to an adult and report them.

### 🏆 Competitions and events

#### [CoderDojo clubs](https://coderdojo.com/)

Volunteer clubs where a child picks their own project (Scratch, web, games) and a mentor helps them. Great for independent, curious makers.

:::reveal How to join
*club · Free (a basic rule of the CoderDojo movement) · Czech*

**When:** Regular meetings in each club; check the current list of clubs and dates on the website (the source is from 2019) **Age:** 7–17 years

1. Find your nearest club (library, company, school) on the CoderDojo ČR website.
2. Book a place at a meeting; younger children come with a parent.
3. Bring a laptop if you have one.
:::

#### [CS50x (Harvard, edX)](https://cs50.harvard.edu/x/)

A university introduction to computer science, from C through Python and SQL to the web. For motivated 14- to 15-year-olds it is a big challenge.

:::reveal How to join
*online course · the course is free, a verified certificate costs money · English (subtitles in many languages)*

**When:** The new CS50x 2026 version runs from 1 January 2026, you can start the course at any time **Age:** edX from 13; the content suits 14+ better

1. materials free on cs50.harvard.edu
2. assignments via edX or GitHub (mind the account’s age limit)
:::

#### [Code Club (Raspberry Pi Foundation)](https://codeclub.org/)

Step-by-step projects (Scratch, Python, web, physical devices) run by volunteers.

:::reveal How to join
*network of clubs · free · projects in many languages*

**When:** during the school year, depending on the club **Age:** about 9–13 years

1. find a club on codeclub.org or start a club at your school
:::

#### [Khan Academy – Computing](https://www.khanacademy.org/computing)

Interactive courses in JavaScript, drawing with code and SQL at your own pace.

:::reveal How to join
*online courses · free · English, some content translated*

**When:** all year **Age:** under 13 via a parent’s or teacher’s account

1. a parent creates a child account, or a teacher creates a class
:::

### 🧪 Projects for inspiration

- **[neal.fun and its Internet Artifacts](https://waxy.org/2023/10/neal-funs-internet-artifacts-an-online-museum-of-artifacts-from-the-early-internet/)**: Neal Agarwal’s website with one-page toys and a museum of the early internet, where even old websites work. *You will learn:* How one idea can carry a whole page. In F12, find out how many files and kilobytes one toy needs. In English.
- **[js13kGames 2025 winners](https://dev.to/js13kgames/js13kgames-2025-winners-announced-20nl)**: Award-winning web games, each of which fits into 13 kilobytes. *You will learn:* What an extreme size budget looks like and how to save: drawing with code instead of images, sound generated by a script. In English.
- **[Flexbox Froggy as a website](https://flexboxfroggy.com)**: A learning game that is itself an ordinary web page in HTML, CSS and JavaScript, in dozens of languages. *You will learn:* Open F12 and find how the game checks your CSS and how it switches languages. An analysis of a website that handles many languages at once.
- **[An article on Wikipedia (for example Hack Club)](https://en.wikipedia.org/wiki/Hack_Club)**: One of the most visited websites in the world, fast and accessible. *You will learn:* Study the heading outline, the image captions and the number of third-party domains. Compare it with a news website.

### 📚 Where to keep learning

- **[MDN Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development)**: A complete course from Mozilla: HTML, CSS, layout, JavaScript, accessibility, performance. Free, under a Creative Commons licence. *(in English)*
- **[20 award-winning games explained (freeCodeCamp)](https://www.freecodecamp.org/news/20-award-winning-games-explained-code-breakdown/)**: A look at the code of award-winning games from the js13kGames competition: how a game fits into 13 kB. *(in English)*
- **[Code.org: Web Lab FAQ](https://support.code.org/hc/en-us/articles/44971343420429-Web-Lab-FAQ)**: A guide to starting a project in Web Lab and what the new version can do. *(in English)*
- **[Hack Club for parents](https://hackclub.com/parents)**: A page for parents: what Hack Club is and how safety works. Good to show at home before you sign up. *(in English)*
