Súbor index.html v tvojom počítači si kamarát neotvorí. Aby web videl ktokoľvek, musí sa presťahovať na počítač, ktorý nikdy nespí.

Ten počítač je **server**: **poskytuje službu** ostatným, tu posiela súbory tvojho webu každému, kto si o ne povie. Miestu na serveri sa hovorí **hosting**. Pre školský web je zadarmo: na GitHub Pages alebo Netlify nahráš priečinok a o minútu máš adresu ako *nas-kruzok.netlify.app*.

Hosting je **cloud**: tvoj web beží na **cudzom počítači** v dátovom centre nejakej firmy. Má to **výhody**: server je zapnutý nonstop, zvládne tisíc návštev naraz a o aktualizácie sa stará firma. A má to **závislosti**: keď firma službu zruší, zdraží alebo ti zablokuje účet, web zmizne. Preto maj súbory webu aj u seba. **Záloha na inom mieste** je tvoja poistka.

**Doména** je meno, ktoré si ľudia zapamätajú:

| | Hosting | Doména |
|---|---|---|
| Čo to je | miesto, kde web beží | meno, ktoré na web ukazuje |
| Príklad | GitHub Pages, Netlify | naskruzok.sk |
| Na začiatok | zadarmo | subdoména zadarmo, .sk za pár eur ročne |

Doména ukazuje na IP adresu servera. Keď sa presťahuješ k inému hostingu, len ju presmeruješ. Meno zostane, server sa vymení.

A kde to dátové centrum stojí? V nejakej **krajine**, a platia tam jej zákony. Keď web zbiera mená a e-maily napríklad cez prihlášku na akciu, ležia tam aj tie dáta. Pre služby v **EÚ** platí **GDPR**, ktoré určuje, čo s osobnými údajmi smú robiť.

**Vyskúšaj to!** Zadaj doménu webu svojej školy do nástroja typu „IP lookup“. Ktorej firme patrí server, na ktorom web beží, a v ktorej krajine stojí?
