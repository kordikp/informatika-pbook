**🛠 Workshop** · step 2 of 5 · [Twelve December puzzles](#expedice-postup-en)

**Blockly Games** is a set of games in the browser. You program by putting blocks together; nothing to install and no account needed.

**In 30 minutes:**
1. (2 min) Open blockly.games and choose the **Maze** game. Switch the language in the menu. If you can’t find Czech there, simple English is enough: *move forward*, *turn left*, *repeat until*, *if path*.
2. (10 min) Go through levels 1 to 6. For each one, set yourself a goal: **as few blocks as possible**. The game shows how many you have.
3. (15 min) Levels 7 to 10 can’t be done blindly any more. You need a **general algorithm** that works even for a maze you see for the first time. Try the rule: *“If there is a path to the left, turn left. Else if there is a path ahead, go ahead. Else turn right.”* This is called the **left-hand rule**: your hand always keeps touching the wall.
4. (3 min) On paper, draw a maze in which your program from level 10 **never finishes**. If you manage it, you have your first own test that breaks the algorithm.

**Success criterion:** level 10 done with one program, and one maze where it fails.

**Next:** the **Turtle** game is turtle graphics with nested loops, and at the end it shows your program as JavaScript. It is the same logic that the extra game with the turtle trains in the Method chapter.
