**🔍 Analysis** · step 1 of 5 · [An appathon in one weekend](#expedice-aplikace-en)

[Spliit](https://github.com/spliit-app/spliit) is an app for splitting shared expenses. It’s free, it has open code (MIT licence) and it was made as an alternative to paid apps. On GitHub it has about 3,000 stars, so lots of people use it and improve it.

Go through the project page just by reading; you don’t need an account. Answer five questions for yourself:

1. **What does the app save?** Total debts, or individual expenses? Why is the second option safer? Remember the challenge “Offline on the bus”.
2. **How does it split a bill?** Spliit can split equally, by shares, by percentages and by exact amounts. Which of these will a troop need where younger members pay half fare?
3. **How does it suggest settling up?** Find the suggested transfers in the description. It’s the same task as in the core “Who owes whom how much”.
4. **What is it built from?** The description has a list of technologies: Next.js, React, a PostgreSQL database. Which of these is frontend and which is backend?
5. **What doesn’t the app need?** Spliit works as a web app that you add to your phone’s home screen. So which permissions does it not want at all?

If you try the app, make up names and amounts. Don’t put your friends’ real data into someone else’s app.

Finally, write down two things you will copy and one you will do differently, because the troop has different needs (for example, who is bringing the tents).
