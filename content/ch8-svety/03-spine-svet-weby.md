**Kde začít stavět:** stačí poznámkový blok a prohlížeč. Napíšeš pár řádků HTML, uložíš je jako `index.html` a soubor otevřeš. Hotovo, máš webovou stránku. Až bude k světu, nahraješ složku na hosting jako [GitHub Pages](https://pages.github.com) nebo Netlify. Je to zdarma a za pár minut máš veřejnou adresu.

**Odkud se web vzal:** vymyslel ho fyzik Tim Berners-Lee v CERN v roce 1989. HTML, adresy URL i jazyk HTTP, kterým si prohlížeč a server povídají, jsou jeho dílo. První web světa, info.cern.ch, si můžeš otevřít dodnes. Internet byl starší, web je jen jedna ze služeb, které na něm běží.

**Mise světa:** [Postav web](#mission-svet-weby). Projdeš všech osm podání a navrhneš web pro kroužek. Mise se počítá do certifikátu Řešitel.
