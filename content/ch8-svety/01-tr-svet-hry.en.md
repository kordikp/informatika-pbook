Every game you play is built from the core ideas of this book. Here you meet them right inside games.

Ten core ideas of the book, told in the world of games. Each telling is short and has a picture, a minigame or a bit of code. They come in the order in which you would build your own game:

1. [A game broken into pieces](#svet-hry-dekompozice-en) · core *Break the problem down*
2. [Hitbox: the knight is a rectangle](#svet-hry-abstrakce-a-model-en) · core *Model: a useful simplification*
3. [The ball that flew through the paddle](#svet-hry-over-a-oprav-en) · core *Test and fix*
4. [The game loop: a loop that never sleeps](#svet-hry-opakovani-en) · core *Repetition (loop)*
5. [When it touches a coin](#svet-hry-rozhodovani-en) · core *Decisions (conditions)*
6. [Score, lives, level](#svet-hry-promenna-en) · core *Variable: a program's memory*
7. [A sprite is a grid of numbers](#svet-hry-kodovani-en) · core *Everything is numbers*
8. [Why an online game lags](#svet-hry-cesta-dat-en) · core *How data travels*
9. [Free skins](#svet-hry-podvod-cili-na-cloveka-en) · core *Scams target people*
10. [The cheat that stole accounts](#svet-hry-ochrana-zarizeni-en) · core *Protecting your devices*

**Where to start building:** [Scratch](https://scratch.mit.edu) runs free in your browser, in many languages. You put a program together from coloured blocks that only click together when they make sense. It has everything from this world: the loop, conditions, variables and collisions. When the blocks start to feel tight, you move on to an engine like Godot and find that you already know the ideas.

![The hoop that won’t let you go](images/comic-ch11-herni-design.en.svg)

**Why a game is fun:** fun can’t be programmed, but it can be designed. The challenge should match what the player can do (too easy is boring, too hard is infuriating). The game should answer every action straight away: clink, flash, points. And the rules should fit in one sentence. The only way to find out whether it works is to give the game to someone else, keep quiet and watch.

**The world’s mission:** [Build a game](#mission-svet-hry). You go through all ten tellings and design your own game. The mission counts towards the Solver certificate.
