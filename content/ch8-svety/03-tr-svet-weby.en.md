You can build a website that a friend on the other side of the world can open in a single afternoon. And on the way you meet a third of the core ideas of this book.

Eight core ideas of the book, told in the world of websites. They come in the order in which a website is made: from a sketch through code to an address you send to your friends:

1. [A sketch and a site map](#svet-weby-abstrakce-a-model-en) · core *Model: a useful simplification*
2. [Three languages of one page](#svet-weby-program-en) · core *Program: input → steps → output*
3. [Scrambled letters](#svet-weby-kodovani-en) · core *Everything is numbers*
4. [What happens when you press Enter](#svet-weby-cesta-dat-en) · core *How data travels*
5. [Where your website lives](#svet-weby-cloud-a-server-en) · core *The cloud is someone else's computer*
6. [The padlock in the address bar](#svet-weby-sifrovani-en) · core *Encryption: an envelope instead of a postcard*
7. [A leak from one forum](#svet-weby-ucet-a-autentizace-en) · core *Account and password*
8. [Cookies: who follows you around the web](#svet-weby-digitalni-stopa-en) · core *Digital footprint*

![Three layers of a website: structure, look and behaviour](images/diagram-tri-vrstvy-webu.en.svg)

**Where to start building:** a text editor and a browser are all you need. You write a few lines of HTML, save them as `index.html` and open the file. Done, you have a web page. When it looks good, you upload the folder to a hosting service like [GitHub Pages](https://pages.github.com) or Netlify. It is free and in a few minutes you have a public address.

**Where the web came from:** the physicist Tim Berners-Lee invented it at CERN in 1989. HTML, URL addresses and HTTP, the language in which a browser and a server talk, are all his work. The world’s first website, info.cern.ch, still opens today. The internet is older; the web is just one of the services that run on it.

**The world’s mission:** [Build a website](#mission-svet-weby). You go through all eight tellings and design a website for a club. The mission counts towards the Solver certificate.
