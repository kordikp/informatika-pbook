Tvoje stránka je hotová, jenže má jednu vadu: vidíš ji jen ty. Soubor `index.html` v tvém počítači si kamarád neotevře. Aby web viděl kdokoli na světě, potřebuje dvě věci — a obě už vlastně chápeš.

**1. Hosting: místo, kde web běží.** Z první kapitoly víš, že stránky „bydlí" na serverech. Hosting znamená přesně tohle: pronajmeš si (nebo dostaneš zdarma) kousek serveru, nahraješ na něj svoje soubory — a od té chvíle je server ochotně posílá každému prohlížeči, který o ně požádá. Tvůj web se stal jedním z těch, o kterých byla sekce „jak funguje web", jen na straně odpovídajícího.

**2. Doména: adresa, kterou si lidi zapamatují.** Server má číselnou adresu, ale „navštiv 172.67.183.2" nikomu neřekneš. Doména je jméno — `mujweb.cz`, `skolni-casopis.eu` — které se na server ukazuje. O překlad jména na číslo se stará systém DNS, takový telefonní seznam internetu. Domény se registrují (ta hezká .cz stojí pár stovek ročně), ale pro začátek dostaneš zadarmo poddoménu od hostingu — třeba `mujweb.netlify.app`.

| | Hosting | Doména |
|---|---|---|
| Co to je | místo, kde web běží (server) | zapamatovatelná adresa |
| Příklad | Netlify, GitHub Pages, Vercel | mujweb.cz |
| Cena pro start | zdarma | zdarma poddoména, .cz ~stovky Kč/rok |
| Analogie | pozemek s domem | cedule s adresou |

A teď ta nejlepší zpráva: **publikovat web dnes zvládneš zdarma a za pár minut.** Služby jako GitHub Pages, Netlify nebo Vercel fungují tak, že soubory přetáhneš myší nebo propojíš s úložištěm — a za chvíli máš veřejnou adresu. Žádné poplatky, žádná instalace. To, co bývalo práce pro firmy, je dnes páteční večer osmáka.

Jen s veřejností přichází zodpovědnost, kterou už znáš z kapitol o bezpečnosti a občanství: **na veřejný web patří jen to, co může vidět celý svět.** Žádná adresa bydliště, telefon, ani fotky spolužáků bez jejich souhlasu. Web je tvoje výkladní skříň — a taky tvoje digitální stopa.

**Zkus to!** Publikuj svou stránku z minulých sekcí (učitel nebo návod hostingu tě provede — na Netlify to je doslova přetažení složky). Pak pošli adresu kamarádovi a nech si to potvrdit: „vidím to!" Tenhle moment si užij — právě jsi přidal svůj kousek do World Wide Webu.

> **Věděl/a jsi?** Česká národní doména .cz patří mezi nejbezpečnější na světě i díky sdružení CZ.NIC, které ji spravuje. Registrovaných .cz domén jsou přes milion — a jedna z nich může být klidně tvoje.

Web žije a je venku. Poslední vrstva ho naučí reagovat: JavaScript.
