**🛠️ Side trip** · [Operation Flag](#expedice-bezpeci-en)

**Bandit** is a “wargame” for complete beginners. On each level you connect to a server through the terminal (the `ssh` command) and look for the password to the next level. The servers are built to be “attacked”, so it’s legal. It’s free, no account, in English.

**How to start:** open [Bandit](https://overthewire.org/wargames/bandit/) and read Level 0. On Windows use PowerShell, on a Mac or in Linux use Terminal. The first time, try it with an adult, so you’re not scared of the black window.

**Your challenge:** get to at least level 5 and for each one write down in your notebook a new command and what it does (for example `ls`, `cat`, `find`). Write level passwords only in your notebook, never in a chat or on a website.

Stuck? First read the hint for the level and the command’s manual (`man find`). Only then reach for the [freeCodeCamp walkthrough](https://www.freecodecamp.org/news/improve-you-cybersecurity-command-line-skills-bandit-overthewire-game-walkthrough/), which contains the solutions. Anyone who masters the terminal has an open door to Linux, servers and real security work.
