**🛠️ Kitérő** · [Tizenkét csillag](#expedice-program-hu)

Játszd végig a [Learn Git Branching](https://learngitbranching.js.org/) teljes bevezető sorozatát, és a homokozóban próbálj ki egy ágat: hozd létre a `proba` ágat, készíts rajta két commitot, és egyesítsd vissza. Aztán a szülőd engedélyével telepítsd a Gitet a gépedre. A rejtvényed mappájában futtasd a parancssorban a `git init`, majd a `git add hadanka.py` és a `git commit -m "2. rész hozzáadása: legnagyobb melegedés"` parancsot. Minden működő változtatás után készíts újabb commitot. A `git log` parancs kiírja a történetet, ugyanúgy, mint a GitHubon egy nagy projektnél. Aztán próbálj meg szándékosan elrontani valamit, és visszatérni az utolsó működő változathoz. A nyilvános GitHubra a projekteddel csak 13 éves kortól menj, vagy a szülőd fiókján keresztül.
