**👀 Kitérő** · [Tizenkét csillag](#expedice-program-hu)

A JavaScript olyan nyelv, amelyet minden böngésző ismer. Számítógépen nyomd meg az **F12**-t, és nyisd meg a **Console** fület. Írd be: `2 + 3`, és Enter, a válasz 5. Most írd át a hőmérőt: a lista `let fokok = [-3, -1, 2, 5, 4, 0, -2, -6];`, a ciklus `for (const t of fokok) { … }`, a feltétel `if (t < 0) { szamlalo = szamlalo + 1; }`, a kiírás pedig `console.log(szamlalo);`. Hasonlítsd össze a két programot egymás mellett: az algoritmus ugyanaz, a zárójelek és a pontosvesszők különböznek. A Python behúz, a JavaScript zárójelez. Aki JavaScriptben játékokat akar építeni, nézze meg a [js13kGames](https://js13kgames.com/) oldalt: az egész játéknak bele kell férnie 13 kB-ba. A nyertes játékok kódjának elemzését a [freeCodeCampen](https://www.freecodecamp.org/news/20-award-winning-games-explained-code-breakdown/) találod (angolul). A versenyre csak szülővel jelentkezz.
