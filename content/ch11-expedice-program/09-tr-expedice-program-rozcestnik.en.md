Real tools, communities, competitions and projects where you can keep going. This selection is from October 2026: rules, prices and dates change, so always check them on the website. Before you sign up anywhere, read the page [Safe in communities](#bezpecne-v-komunitach-en).

### 🛠 Tools

#### [Thonny](https://thonny.org/)

A Python editor for beginners, version 5.0.1 with Python 3.14. It has stepping (Ctrl+F5, F6 big step, F7 small step) and a variables window.

:::reveal How to start
It shows step by step how an expression is worked out and how a box changes. It’s the trace table from the core “Variable: a program's memory”, only the computer draws it. It can also switch to MicroPython for the micro:bit.

*free, open source · no account, no age limit; a parent approves installing it on the computer · in English (the interface has translations; you switch the language in the settings)*

1. Download the installer for your system from thonny.org (with a parent).
2. Type print("Hi") into the editor and run it with the F5 key.
3. Turn on View → Variables and step through the program with Ctrl+F5 and F7.
:::

#### [Python Tutor](https://pythontutor.com/)

A website where you write code (Python, JavaScript, Java, C, C++) and see it run step by step: variables, lists and function calls. With a slider you go forwards and backwards.

:::reveal How to start
Nothing to install. The quickest way to check your solutions to the challenges and see why a loop ended, or didn’t.

*free · no account, no age limit; use the built-in AI tutor only with care · in English (you write the code in Python or JavaScript)*

1. Open pythontutor.com and choose Python.
2. Paste in the program from the challenge and click Visualize Execution.
3. Move the slider forwards and backwards and watch when each box changes.
:::

#### [EduBlocks](https://edublocks.org/)

Blocks that write real Python: each block is one line, and the text appears right next to it. Modes for Python, HTML, micro:bit, CircuitPython and Raspberry Pi.

:::reveal How to start
A bridge from Scratch to text. You build a loop out of blocks and see what it looks like in Python, indentation and all.

*free (a tool from the company Anaconda) · editor in the browser; sort out registration (not needed to try it) with a parent · in English*

1. On edublocks.org, click Start Coding and choose Python.
2. Build a loop with a condition out of blocks and read the text next to it.
3. Write the same program straight in text and compare.
:::

#### [Learn Git Branching](https://learngitbranching.js.org/)

A browser game that teaches Git level by level: commit, branches, merge, rebase. It also has a sandbox for your own experiments.

:::reveal How to start
Git is a programmer’s memory, and here you can learn it with no installation and no risk of breaking anything.

*free, open source (MIT) · no account, no age limit · in English*

1. Open the page and go through the opening dialogue.
2. Start with the first level and type commands like git commit.
3. In the sandbox, draw the history of your own project.
:::

#### [Snap!](https://snap.berkeley.edu/)

A block language from the university in Berkeley, similar to Scratch. But it can do custom blocks with parameters, recursion and lists as values.

:::reveal How to start
For those for whom Scratch isn’t enough but who don’t want to move to text yet. People even solve Advent of Code puzzles in it.

*free · editor with no account, no limits; account and forum only with a parent · interface in many languages (Czech is in the language menu)*

1. Open the editor and make your own block “square with side s”.
2. Try a block that calls itself (recursion), and don’t forget the stopping condition.
3. Read on the forum how others solved an Advent of Code puzzle in blocks.
:::

### 👥 Communities

#### [Advent of Code](https://adventofcode.com/)

*online puzzles (December); since 2025, twelve puzzles and only private leaderboards · free · in English; you can solve it in any language, even in blocks*

:::reveal How to join
**Age:** the website gives no age; login only through other services (GitHub, Reddit), which are for ages 13 and up. Younger: a parent’s account, or just the examples from the puzzles without logging in

1. From 1 December, one puzzle comes out every day, twelve in all, and they stay on the website afterwards too.
2. First solve the example from the puzzle by hand, then with a program.
3. A parent or the club leader sets up a private leaderboard with your friends.
:::

> **Stay safe:** Only a nickname, no name or school. Don’t share the puzzles or input data; they belong to the author. The author asks people not to solve the puzzles with AI.

#### [js13kGames](https://js13kgames.com/)

*a JavaScript game jam: the whole game in 13 kB, with the theme announced at the start (usually August to September; the 2026 edition has already taken place) · free · in English; JavaScript*

:::reveal How to join
**Age:** entries are submitted through GitHub (13 and up); younger kids with a parent, or just play and read the games’ code

1. Play games from past years and open their code.
2. Write a small practice game in JavaScript outside the competition.
3. Enter the competition with a parent who has a GitHub account.
:::

> **Stay safe:** No personal details in your profile or in the game. Talk on Discord and other networks only with a parent. Read other people’s game code, but don’t copy it without crediting the author.

#### [Coolest Projects online](https://coolestprojects.org/)

*a worldwide showcase of young makers’ projects from the Raspberry Pi Foundation, with no rankings and no stress; entries for the 2027 edition open in January 2027 · free · in English*

:::reveal How to join
**Age:** under 18; you submit your entry together with a parent or club leader

1. Look through the gallery of projects from 2026.
2. Finish your own project from the expedition and film a short video of how it works.
3. In January 2027, enter it with a parent or club leader.
:::

> **Stay safe:** A moderated showcase for kids. Don’t show your face, name or school in the video unless a parent approves. Always do the entry with an adult.

#### [Snap! Forum](https://forum.snap.berkeley.edu/)

*a forum for users of the block language Snap!, for sharing projects and puzzle solutions · free · in English*

:::reveal How to join
**Age:** you can read it without an account; posting only with an account, following the forum rules and with a parent’s consent

1. Read threads with solutions and projects without logging in.
2. If you want to give advice or ask something, create an account together with a parent.
3. Share your project, not personal information.
:::

> **Stay safe:** A nickname instead of your name. Don’t send private messages to people you don’t know. If someone writes to you in a nasty way, show it to a parent and report it to the moderators.

### 🏆 Competitions and events

#### [CoderDojo clubs](https://coderdojo.com/)

Volunteer clubs where a child picks their own project (Scratch, web, games) and a mentor helps them. Great for independent, curious makers.

:::reveal How to join
*club · Free (a basic rule of the CoderDojo movement) · Czech*

**When:** Regular meetings in each club; check the current list of clubs and dates on the website (the source is from 2019) **Age:** 7–17 years

1. Find your nearest club (library, company, school) on the CoderDojo ČR website.
2. Book a place at a meeting; younger children come with a parent.
3. Bring a laptop if you have one.
:::

#### [EJOI – European Junior Olympiad in Informatics](https://www.ejoi2026.mif.vu.lt/about/)

The top goal for 13–15-year-old algorithm fans from Hungary as well as from Czechia and Slovakia.

:::reveal How to join
*olympiad · free when representing your country · tasks in national languages, C++ and others*

**When:** every summer, in 2026 in Lithuania, check the next one on the website **Age:** junior category (younger than IOI), check the exact limit on the website

1. nomination by national selection, in Hungary through home competitions and the olympiad
:::

#### [Hour of Code / Hour of AI (CSEd Week)](https://www.csedweek.org/)

The new Hour of AI version is an easy way into AI and programming. Gifted kids can try the more advanced tutorials here.

:::reveal How to join
*campaign and online activities · free · many languages including Hungarian, Czech and Slovak*

**When:** CS Education Week 2026: 7–13 December 2026 (sources differ by a day, check on code.org) **Age:** from age 4 up

1. you can do the one-hour activity at home or with your class on code.org
:::

#### [USACO – USA Computing Olympiad](https://usaco.org/)

Four divisions (Bronze, Silver, Gold, Platinum) give a clear ladder to climb and a big collection of problems with solutions.

:::reveal How to join
*online competition · free (training); the website does not mention a competition fee, check · English; C++, Java, Python*

**When:** The 2026/27 schedule has not been published yet (as of October 2026). There are usually four online rounds from December to March, check on the website **Age:** no age limit, students of all levels

1. an account on usaco.org
2. you start in the Bronze division
:::

#### [Advent of Code](https://adventofcode.com/)

Story-based puzzles you can solve in any language. Great for solving together in class or as a family.

:::reveal How to join
*online challenge · free · English, any programming language*

**When:** from 1 December (the 2025 edition had only 12 days), check the 2026 edition on the website **Age:** no limit, better from about 13 with some programming experience

1. you log in with an account (GitHub/Google), so mind the account’s age limit
2. a private leaderboard with your class or club
:::

#### [CS50x (Harvard, edX)](https://cs50.harvard.edu/x/)

A university introduction to computer science, from C through Python and SQL to the web. For motivated 14- to 15-year-olds it is a big challenge.

:::reveal How to join
*online course · the course is free, a verified certificate costs money · English (subtitles in many languages)*

**When:** The new CS50x 2026 version runs from 1 January 2026, you can start the course at any time **Age:** edX from 13; the content suits 14+ better

1. materials free on cs50.harvard.edu
2. assignments via edX or GitHub (mind the account’s age limit)
:::

#### [Scratch (MIT)](https://scratch.mit.edu/)

A moderated community where kids share games and animations and get feedback. It follows on from the Hungarian Kovács Mihály/Logo competition.

:::reveal How to join
*creative community · free · dozens of languages including Hungarian*

**When:** all year **Age:** recommended 8–16 years, no fixed limit

1. an account on scratch.mit.edu (younger kids with a parent’s consent)
2. a class account from a teacher
:::

#### [Code Club (Raspberry Pi Foundation)](https://codeclub.org/)

Step-by-step projects (Scratch, Python, web, physical devices) run by volunteers.

:::reveal How to join
*network of clubs · free · projects in many languages*

**When:** during the school year, depending on the club **Age:** about 9–13 years

1. find a club on codeclub.org or start a club at your school
:::

#### [Codeforces](https://codeforces.com/)

The rating keeps you motivated and the regular rounds give competition practice for olympiad solvers.

:::reveal How to join
*regular online rounds · free · English/Russian; C++, Python and others*

**When:** rounds several times a week **Age:** age limit in the terms not verified

1. an account on codeforces.com (check the age)
2. start with Div. 3 and Div. 4 rounds
:::

#### [Khan Academy – Computing](https://www.khanacademy.org/computing)

Interactive courses in JavaScript, drawing with code and SQL at your own pace.

:::reveal How to join
*online courses · free · English, some content translated*

**When:** all year **Age:** under 13 via a parent’s or teacher’s account

1. a parent creates a child account, or a teacher creates a class
:::

### 🧪 Projects for inspiration

- **[Learn Git Branching (source code)](https://github.com/pcottle/learnGitBranching)**: The whole learning game is JavaScript that runs only in the browser, with no server. The code and the commit history are public and can be read without an account. *You will learn:* What the history of a big project looks like, how commit messages are written and how the game’s levels are stored as data.
- **[20 award-winning js13kGames games broken down](https://www.freecodecamp.org/news/20-award-winning-games-explained-code-breakdown/)**: A code breakdown of twenty winning mini-games, each of which fitted into 13 kB of JavaScript (in English). *You will learn:* The game loop, state variables and clever shortcuts. How a whole game fits into a small space.
- **[Advent of Code 2025, day 1 in Snap!](https://forum.snap.berkeley.edu/t/advent-of-code-2025-day-1/20637)**: A thread on the Snap! forum where people share solutions to the first puzzle of 2025 in blocks. You can read it without an account. *You will learn:* Compare a block solution and a text solution to the same problem and see that the algorithm is the same; only the way it’s written differs.
- **[Coolest Projects 2026: a showcase of 15,000 young makers](https://www.raspberrypi.org/blog/celebrating-over-15000-young-creators-at-the-coolest-projects-2026-online-showcase/)**: A summary of the worldwide online showcase of projects by people under 18 from the Raspberry Pi Foundation, with links to the gallery (in English). *You will learn:* What people your age build: games, apps, robots. Inspiration and a yardstick for your own project from the expedition.
