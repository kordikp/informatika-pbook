**👀 Odbočka** · [Dvanáct hvězd](#expedice-program)

JavaScript je jazyk, který umí každý prohlížeč. Na počítači stiskni **F12** a otevři záložku **Console**. Napiš `2 + 3` a Enter, odpoví 5. Teď přepiš teploměr: seznam je `let teploty = [-3, -1, 2, 5, 4, 0, -2, -6];`, cyklus `for (const t of teploty) { … }`, podmínka `if (t < 0) { pocet = pocet + 1; }` a výpis `console.log(pocet);`. Porovnej oba programy vedle sebe: algoritmus je stejný, liší se závorky a středníky. Python odsazuje, JavaScript závorkuje. Kdo chce v JavaScriptu stavět hry, může se podívat na [js13kGames](https://js13kgames.com/): celá hra se musí vejít do 13 kB. Kód vítězných her najdeš rozebraný na [freeCodeCamp](https://www.freecodecamp.org/news/20-award-winning-games-explained-code-breakdown/) (anglicky). Do soutěže se přihlašuj jen s rodičem.
