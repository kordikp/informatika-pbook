**👀 Odbočka** · [Dvanásť hviezd](#expedice-program-sk)

JavaScript je jazyk, ktorý vie každý prehliadač. Na počítači stlač **F12** a otvor záložku **Console**. Napíš `2 + 3` a Enter, odpovie 5. Teraz prepíš teplomer: zoznam je `let teploty = [-3, -1, 2, 5, 4, 0, -2, -6];`, cyklus `for (const t of teploty) { … }`, podmienka `if (t < 0) { pocet = pocet + 1; }` a výpis `console.log(pocet);`. Porovnaj oba programy vedľa seba: algoritmus je rovnaký, líšia sa zátvorky a bodkočiarky. Python odsadzuje, JavaScript zátvorkuje. Kto chce v JavaScripte stavať hry, môže sa pozrieť na [js13kGames](https://js13kgames.com/): celá hra sa musí zmestiť do 13 kB. Kód víťazných hier nájdeš rozobraný na [freeCodeCamp](https://www.freecodecamp.org/news/20-award-winning-games-explained-code-breakdown/) (po anglicky). Do súťaže sa prihlasuj len s rodičom.
