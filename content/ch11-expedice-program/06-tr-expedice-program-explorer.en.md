**👀 Side trip** · [Twelve stars](#expedice-program-en)

JavaScript is a language every browser understands. On a computer, press **F12** and open the **Console** tab. Type `2 + 3` and press Enter; it answers 5. Now rewrite the thermometer: the list is `let temps = [-3, -1, 2, 5, 4, 0, -2, -6];`, the loop `for (const t of temps) { … }`, the condition `if (t < 0) { count = count + 1; }` and the output `console.log(count);`. Compare the two programs side by side: the algorithm is the same; the brackets and semicolons differ. Python indents, JavaScript uses brackets. If you want to build games in JavaScript, take a look at [js13kGames](https://js13kgames.com/): the whole game has to fit into 13 kB. You can find the code of winning games broken down on [freeCodeCamp](https://www.freecodecamp.org/news/20-award-winning-games-explained-code-breakdown/) (in English). Only enter the competition with a parent.
