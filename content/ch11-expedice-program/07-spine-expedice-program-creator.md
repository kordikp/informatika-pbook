**🛠️ Odbočka** · [Dvanáct hvězd](#expedice-program)

Dohraj v [Learn Git Branching](https://learngitbranching.js.org/) celou úvodní sadu a v pískovišti si zkus větev: vytvoř `pokus`, udělej na ní dva commity a spoj ji zpátky. Pak, se svolením rodiče, nainstaluj Git do počítače. Ve složce s hádankou spusť v příkazové řádce `git init`, potom `git add hadanka.py` a `git commit -m "Přidej část 2: největší oteplení"`. Po každé funkční změně udělej další commit. Příkaz `git log` ti vypíše historii, stejně jako na GitHubu u velkého projektu. Zkus pak schválně něco rozbít a vrátit se k poslední funkční verzi. Na veřejný GitHub se svým projektem jdi až od 13 let, nebo přes účet rodiče.
