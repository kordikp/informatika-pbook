**🛠️ Side trip** · [Twelve stars](#expedice-program-en)

Finish the whole introductory set in [Learn Git Branching](https://learngitbranching.js.org/) and try a branch in the sandbox: create `experiment`, make two commits on it and merge it back. Then, with a parent’s permission, install Git on your computer. In the folder with your puzzle, run `git init` in the command line, then `git add puzzle.py` and `git commit -m "Add part 2: biggest temperature rise"`. After every working change, make another commit. The command `git log` shows you the history, just like on GitHub for a big project. Then try breaking something on purpose and going back to the last working version. Only put your project on public GitHub from age 13, or through a parent’s account.
