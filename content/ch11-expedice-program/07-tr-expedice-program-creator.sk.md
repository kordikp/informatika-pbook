**🛠️ Odbočka** · [Dvanásť hviezd](#expedice-program-sk)

Dohraj v [Learn Git Branching](https://learngitbranching.js.org/) celú úvodnú sadu a v pieskovisku si skús vetvu: vytvor `pokus`, urob na nej dva commity a spoj ju späť. Potom, so súhlasom rodiča, nainštaluj Git do počítača. V priečinku s hádankou spusti v príkazovom riadku `git init`, potom `git add hadanka.py` a `git commit -m "Pridaj časť 2: najväčšie oteplenie"`. Po každej funkčnej zmene urob ďalší commit. Príkaz `git log` ti vypíše históriu, rovnako ako na GitHube pri veľkom projekte. Skús potom schválne niečo pokaziť a vrátiť sa k poslednej funkčnej verzii. Na verejný GitHub so svojím projektom choď až od 13 rokov, alebo cez účet rodiča.
